# The certificates emudhra-patch finds on a computer and distrusts.
#
# One certificate a line, its fields separated by tabs:
#
#   Name    Kind    Reference    Serial    SHA-256 fingerprint
#
# The SHA-256 fingerprint (64 hex digits, the last field) is what a certificate is matched by; the serial is
# checked against the certificate's PEM in certs\ when there is one, and shown. Name, kind and reference are for
# people. A line that starts with # is a comment: put # in front of a line to leave that certificate alone.
#
# certs\<SHA-256>.pem holds each certificate itself. A certificate with a PEM there is distrusted even on a computer
# that does not have it yet (Windows fetches roots it trusts only when they are first needed, so a root that is
# missing today can arrive tomorrow); one without a PEM is only removed where it is found.
#
# Besides these, emudhra-patch distrusts every certificate it finds that has the public key of one listed here
# (another issue or cross-signature of the same CA), and the certificates that issued them, up to the root.
